## 协调者只做一次的准备

先将本任务包与当前代码一起提交并同步到三人；本轮整理文档没有替你执行暂存、提交或推送。同机工作时，在包含本任务包的共同提交上创建三个独立工作区（目录/分支已存在则检查并复用，不 force 或覆盖）：

```sh
git worktree add -b feat/sdk54-abc-a ../expo-harmony-sdk54-a HEAD
git worktree add -b feat/sdk54-abc-b ../expo-harmony-sdk54-b HEAD
git worktree add -b feat/sdk54-abc-c ../expo-harmony-sdk54-c HEAD
```

分别在三个目录打开 Codex。不同机器则各自克隆同一提交后建立自己的角色分支。把补充材料 tar 放到各 checkout 的父目录；同机可以共享只读 tar，各自解压、各自消费者和输出目录。没有设备的成员可以先做源码/主机任务，设备验收必须在有 SDK/设备且分配了 target 的环境完成。
